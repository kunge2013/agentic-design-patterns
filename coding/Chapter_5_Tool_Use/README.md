# 第五章：工具使用 - 代码示例

本目录包含第五章"工具使用"的代码实现示例，展示了如何通过工具调用机制扩展智能体的能力。

## 文件说明

### 1. [basic-tool-use.py](1-basic-tool-use.py)
**目的：** 演示 LangChain 框架中基础工具使用的实现

**功能：**
- 实现工具调用的完整流程：定义、决策、执行、处理
- 创建搜索信息和数学计算两个基础工具
- 使用 create_tool_calling_agent 创建工具调用智能体
- 展示 AgentExecutor 如何管理工具执行

**核心概念：**
- 工具定义：使用 @tool 装饰器定义工具
- LLM 决策：智能体决定何时使用工具
- 函数调用生成：LLM 生成结构化的工具调用请求
- 工具执行：AgentExecutor 执行实际函数调用
- 结果处理：将工具结果返回给 LLM 生成最终响应

### 2. [financial-agent.py](2-financial-agent.py)
**目的：** 演示专门的金融分析智能体，使用多个工具进行金融分析

**功能：**
- 股票价格查询工具：获取模拟的实时股票价格
- 投资回报率计算工具：计算 ROI 并提供投资分析
- 投资建议生成工具：基于价格和持仓期提供智能建议
- 市场情绪分析工具：分析特定股票的市场情绪

**核心概念：**
- 领域专业化：创建专门领域的智能体
- 多工具协作：多个工具协同工作解决复杂问题
- 数据模拟：使用模拟数据演示真实场景
- 错误处理：处理工具调用中的异常情况

### 3. [multi-tool-collaboration.py](3-multi-tool-collaboration.py)
**目的：** 演示多工具协作的复杂智能体

**功能：**
- 天气查询工具：获取指定位置的天气信息
- 货币转换工具：执行货币转换和汇率查询
- 旅行距离计算工具：计算城市间的直线距离
- 旅行时间估算工具：基于距离和交通方式估算时间
- 智能旅行建议工具：提供综合旅行规划建议

**核心概念：**
- 工具链：一个工具的输出作为另一个工具的输入
- 多工具整合：整合多个工具的结果
- 复杂任务分解：将复杂任务分解为多个工具调用
- 上下文保持：在工具调用之间维护上下文信息

### 4. [code-execution-agent.py](4-code-execution-agent.py)
**目的：** 演示代码执行工具的实现和使用

**功能：**
- 安全代码执行工具：在沙盒环境中执行 Python 代码
- 数学计算工具：支持复杂数学表达式计算
- 数据分析工具：对数据集进行统计分析
- 文本处理工具：处理和分析文本数据

**核心概念：**
- 沙盒执行：在受限环境中安全执行代码
- 精确计算：通过代码执行实现确定性计算
- 数据处理：使用代码进行复杂的数据分析
- 安全性：限制可用的函数和模块

## 运行要求

### 环境配置
1. 确保安装了必要的依赖包：
```bash
pip install langchain langchain-openai langchain-core langchain
python-dotenv
```

2. 创建 `.env` 文件并添加 API 密钥：
```
OPENAI_API_KEY=your_api_key_here
```

### 运行示例
每个示例都可以独立运行：
```bash
# 基础工具使用
python 1-basic-tool-use.py

# 金融分析智能体
python 2-financial-agent.py

# 多工具协作
python 3-multi-tool-collaboration.py

# 代码执行智能体
python 4-code-execution-agent.py
```

## 工具使用模式的关键特性

1. **外部交互能力：** 智能体能够与外部系统交互
2. **动态信息获取：** 访问实时数据和非静态信息
3. **精确计算：** 通过工具执行确定性计算
4. **操作执行：** 触发外部系统中的操作
5. **知识扩展：** 突破 LLM 训练数据的限制

## 工具调用的六个步骤

1. **工具定义：** 向 LLM 描述外部函数及其参数
2. **LLM 决策：** LLM 基于请求和工具定义决定是否需要调用工具
3. **函数调用生成：** LLM 生成结构化的工具调用请求（JSON 格式）
4. **工具执行：** 智能体框架执行实际的函数调用
5. **观察/结果：** 工具执行结果返回给智能体
6. **LLM 处理：** LLM 使用工具结果生成最终响应

## 技术栈

- **LangChain：** 工具定义、智能体创建、执行管理
- **OpenAI：** GPT-4o 模型，支持函数调用
- **Python：** 工具函数实现
- **异步支持：** 异步工具执行

## 最佳实践

### 1. 工具设计
- 使用清晰的函数名称和描述
- 定义明确的参数类型和描述
- 返回结构化的数据格式
- 包含适当的错误处理

### 2. 安全考虑
- 限制代码执行环境的访问权限
- 验证输入参数
- 处理敏感数据时使用安全方法
- 避免在工具结果中暴露敏感信息

### 3. 性能优化
- 缓存常用查询结果
- 并行执行独立的工具调用
- 优化工具响应时间
- 管理工具调用的频率

### 4. 错误处理
- 提供清晰的错误信息
- 实现重试逻辑
- 处理超时情况
- 提供降级方案

## 扩展建议

1. **更多工具类型：** 集成更多种类的工具
2. **工具参数验证：** 实现严格的参数验证
3. **工具权限管理：** 实现细粒度的工具访问控制
4. **工具监控：** 添加工具使用的监控和日志
5. **动态工具加载：** 支持运行时动态加载工具

## 与其他模式的集成

工具使用模式可以与以下模式结合使用：

- **反思模式：** 工具调用结果作为反思的输入
- **路由模式：** 根据工具选择结果路由到不同处理流程
- **并行化模式：** 并行执行多个工具调用
- **提示词链：** 将工具调用结果传递给下一个提示词

## 注意事项

1. **API 限制：** 注意外部 API 的调用频率和限制
2. **成本控制：** 监控 API 调用成本
3. **数据隐私：** 处理敏感数据时遵守隐私要求
4. **错误恢复：** 设计健壮的错误恢复机制
5. **响应时间：** 考虑工具调用对整体响应时间的影响
