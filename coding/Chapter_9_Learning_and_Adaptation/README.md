# 第9章 学习和适应

本章代码示例展示了智能体如何通过反馈学习和自我改进来提升性能。

## 目录

- [1-learning-adaptation.py](1-learning-adaptation.py) - 学习和适应示例（使用真实LLM）
- [llm_config.py](llm_config.py) - LLM 配置模块

## 文件说明

### 1-learning-adaptation.py

演示了学习和适应的核心机制，**所有演示都使用真实的LLM调用**：

1. **基于反馈的学习** - 智能体使用LLM执行任务并从反馈中调整策略
2. **自我改进** - 智能体使用LLM评估自身能力并生成改进方案
3. **进化优化** - 使用进化算法优化解决方案

**重要特性：**
- 所有任务执行都通过LLM完成，提供真实的智能响应
- 自我评估使用LLM生成详细的能力分析
- 改进建议由LLM根据评估结果智能生成
- 提供降级策略：LLM调用失败时自动回退到模拟模式

运行方式：
```bash
python 1-learning-adaptation.py
```

### llm_config.py

LLM 配置模块，支持多种兼容 OpenAI API 的服务。

## 核心概念

### 基于反馈的学习
智能体通过接收反馈（正向/负向/中性）来调整其参数和策略，逐步改进性能。

### 自我改进（SICA 概念）
智能体能够：
- 自我评估当前能力
- 识别需要改进的领域
- 生成改进方案
- 实施改进
- 重复迭代直到达到目标

### 进化优化
使用进化算法优化解决方案：
- 变异（Mutation）- 生成新变体
- 交叉（Crossover）- 组合优秀解
- 选择（Selection）- 选择适应度高的个体

## 学习方法

1. **强化学习** - 通过奖励和惩罚学习最优策略
2. **监督学习** - 从标注示例学习
3. **无监督学习** - 从未标注数据中发现模式
4. **在线学习** - 持续更新知识库
5. **基于记忆的学习** - 利用过往经验调整行为

## 应用场景

- 个性化助手 - 学习用户偏好
- 交易机器人 - 适应市场变化
- 推荐系统 - 优化推荐算法
- 游戏AI - 提升游戏策略
- 代码智能体 - 自动改进代码质量
