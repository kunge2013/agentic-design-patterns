# 第四章：反思模式 - 代码示例

本目录包含第四章"反思模式"的代码实现示例，展示了如何使用反思模式来改进智能体的输出质量。

## 文件说明

### 1. [code-reflection-loop.py](1-code-reflection-loop.py)
**目的：** 演示完整的代码反思循环，展示如何迭代改进 Python 代码

**功能：**
- 实现了生成器-评审者模型
- 创建一个计算阶乘的 Python 函数
- 通过多个迭代周期进行代码反思和改进
- 使用不同的系统提示来扮演生成器和评审者角色

**核心概念：**
- 反思循环的四个步骤：执行、评估、反思、迭代
- 对话历史管理，为每次迭代提供上下文
- 停止条件（代码完美或达到最大迭代次数）
- 使用 LangChain 的 LCEL 和消息历史

### 2. [generator-reviewer-agents.py](2-generator-reviewer-agents.py)
**目的：** 演示生成器-评审者智能体模型在内容生成中的应用

**功能：**
- 实现了分离的生成器和评审者智能体
- GeneratorAgent：负责创建初始内容
- ReviewerAgent：负责评估内容质量并提供结构化反馈
- SequentialAgent：管理生成器和评审者的执行顺序

**核心概念：**
- 关注点分离：生成和评审逻辑分离
- 结构化反馈：状态和推理的分离开
- 管道式执行：生成→评审→结果
- 事实核查和质量保证

### 3. [self-reflection-agent.py](3-self-reflection-agent.py)
**目的：** 演示单个智能体如何进行自我反思

**功能：**
- 实现了单个智能体的自我反思能力
- 通过角色切换来模拟生成-评审-改进流程
- 支持多种角色（作家、编辑、批评家）
- 自动迭代直到获得满意结果

**核心概念：**
- 自我反思：单个智能体评估自身工作
- 角色切换：在生成者和评审者角色间切换
- 认知偏差管理：避免自我评审中的偏袒
- 多轮对话管理

### 4. [iterative-planning-reflection.py](4-iterative-planning-reflection.py)
**目的：** 演示反思模式在复杂任务规划中的应用

**功能：**
- 实现了规划反思系统
- 生成、评估和优化行动计划
- 支持复杂问题解决的迭代反思
- 协作式反思：多个专家视角的评审

**核心概念：**
- 迭代规划：反复改进计划
- 约束条件处理：在评估中检查约束
- 风险评估：识别潜在问题
- 协作评审：多个专业视角

## 运行要求

### 环境配置
1. 确保安装了必要的依赖包：
```bash
pip install langchain langchain-community langchain-openai python-dotenv
```

2. 创建 `.env` 文件并添加 API 密钥：
```
OPENAI_API_KEY=your_api_key_here
```

### 运行示例
每个示例都可以独立运行：
```bash
# 代码反思循环
python 1-code-reflection-loop.py

# 生成器-评审者智能体
python 2-generator-reviewer-agents.py

# 自我反思智能体
python 3-self-reflection-agent.py

# 迭代规划反思
python 4-iterative-planning-reflection.py
```

## 反思模式的关键特性

1. **自我纠正能力：** 智能体能够识别和修复自身错误
2. **迭代改进：** 通过多轮反思提升输出质量
3. **客观性：** 使用独立评审者减少认知偏差
4. **上下文感知：** 利用对话历史提供丰富上下文
5. **质量控制：** 建立结构化的质量评估机制

## 应用场景

- 代码生成与调试
- 创意写作和内容生成
- 复杂问题解决
- 规划与策略制定
- 摘要与信息综合
- 对话智能体优化

## 注意事项

1. **成本考虑：** 迭代反思会增加 API 调用次数和成本
2. **延迟管理：** 多轮反思会增加响应时间
3. **上下文窗口：** 长对话历史可能超出模型限制
4. **停止条件：** 需要设计合理的停止条件避免无限循环

## 技术栈

- **LangChain：** LCEL、链、提示模板
- **OpenAI：** GPT-4o 模型
- **Python：** 面向对象编程、类设计
- **异步支持：** 可扩展为异步执行

## 扩展建议

1. **集成 LangGraph：** 使用有状态的图结构管理复杂反思流程
2. **多智能体协作：** 引入更多专业化的评审者智能体
3. **性能监控：** 添加反思周期的性能指标
4. **自适应迭代：** 根据问题复杂度动态调整迭代次数
